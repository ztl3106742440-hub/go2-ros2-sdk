# 实验 3：IMU 感知与反馈控制

## 本周目标

将实验 2 的开环运动升级为“感知 → 判断 → 执行”的反馈控制。

## 控制规则

默认规则由 `config/default.json` 配置：

| 状态 | 默认条件 | 控制动作 |
|---|---|---|
| 正常 | Pitch、Roll 均处于安全范围 | 正常速度前进 |
| 预警 | 倾斜进入预警区 | 自动减速 |
| 危险 | 倾斜超过停止阈值 | 立即停止 |
| 数据异常 | 状态长时间未更新 | 立即停止 |

真机拍摄前应先测量正常站立、启动、停止和缓坡时的姿态数据，再确定最终阈值。

## 实验步骤

### 1. 离线观察反馈切换

Mock 场景会自动模拟正常、倾斜和危险倾斜：

```bash
python3 03_IMU反馈控制/run_experiment.py --mock --duration 8
```

### 2. 真机只读验证阈值

不加 `--arm` 时程序不会发送运动指令，可先观察判断结果：

```bash
python3 03_IMU反馈控制/run_experiment.py --interface enp111s0 --duration 30
```

### 3. 真机低速反馈行走

```bash
python3 03_IMU反馈控制/run_experiment.py --interface enp111s0 --duration 30 --arm
```

## 预期现象

- 正常姿态时输出 `normal`。
- 倾斜进入预警区时输出 `tilt_slow`。
- 倾斜过大时输出 `tilt_stop`，运动指令归零。
- 状态超时同样停止。

## 学生任务

在 Pitch 保护基础上，解释为什么还需要 Roll 横向倾斜保护，并比较不同阈值的效果。

## 验收标准

- 能说明开环和闭环控制的区别。
- 减速和停止条件均能触发。
- 数据超时时采取停止策略。
