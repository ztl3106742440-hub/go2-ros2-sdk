# 真机验证清单

按顺序验证，上一层不通过时不要继续发送运动命令。

## L0：环境

- [ ] Go2 EDU 电量充足。
- [ ] 开发机通过网线连接机器狗。
- [ ] 网卡名称确认为 `enp111s0`，或已修改参数。
- [ ] `unitree_sdk2py` 可以正常导入。
- [ ] 手柄接管正常。

## L1：状态只读

- [ ] `rt/lowstate` 能读取电量和 IMU。
- [ ] `rt/sportmodestate` 能读取 RPY 和速度。
- [ ] 状态频率稳定，无明显长时间中断。

## L2：雷达只读

- [ ] 确认纯 SDK Python 实际可订阅的 UTLidar DDS 话题。
- [ ] 输出 PointCloud2 字段、点数和频率。
- [ ] 确认 X/Y/Z 与机体前、左、上的对应关系。
- [ ] 箱子放在前、左、右时，对应扇区距离正确变化。
- [ ] 确认地面和狗腿点不会持续触发前方障碍。

## L3：单动作

- [ ] `Move(vx, 0, 0)` 低速前进正确。
- [ ] `Move(0, vy, 0)` 横移方向正确。
- [ ] `Move(0, 0, vyaw)` 转向方向正确。
- [ ] `StopMove()` 能可靠停止。
- [ ] 程序异常退出后机器狗停止。

## L4：反馈控制

- [ ] 正常行走不会误触发停止。
- [ ] 进入预警倾斜区会减速。
- [ ] 超过停止阈值会停止。
- [ ] 状态超时会停止。

## L5：自主避障

- [ ] 单箱正中位置可以稳定触发。
- [ ] 左右空间不同情况下选择正确。
- [ ] 绕行方向在本轮过程中保持锁定。
- [ ] 绕过障碍后可以恢复前进。
- [ ] 连续 3 次单箱绕行通过。
- [ ] 多箱课程场景通过。
