# 实验 2：运动指令驾驶与路径编程

## 本周目标

使用 `SportClient` 控制 Go2 EDU 前进、后退、横移和转向，并将单个动作组合成路径。

## 核心知识

Go2 机体坐标系：

```text
X：向前为正
Y：向左为正
Yaw：逆时针转向为正
```

官方 SDK 使用统一接口：

```python
sport_client.Move(vx, vy, vyaw)
sport_client.StopMove()
```

课程中的“前进”“右转”等操作，都是对 `Move()` 参数的教学封装。

## 实验步骤

### 1. 离线观察方形路径序列

```bash
python3 02_运动指令与路径编程/run_experiment.py --mock
```

### 2. 真机运动前检查

- 清空机器狗周围区域。
- 确认手柄可以接管。
- 首次运行使用低速参数。
- 真机运动必须显式添加 `--arm`。

```bash
python3 02_运动指令与路径编程/run_experiment.py --interface enp111s0 --arm
```

### 3. 分析路径误差

方形路径采用开环时间控制。观察最终位置与起点之间的误差，并分析地面摩擦、转向
延迟和速度参数对结果的影响。

## 预期现象

- 机器狗依次前进和右转四次。
- 程序每段动作结束后短暂停止。
- 程序异常退出时发送停止命令。

## 学生任务

在方形路径基础上实现三角形路径或 8 字形路径，并记录不同速度下的路径误差。

## 验收标准

- 能解释 `vx`、`vy` 和 `vyaw`。
- 能组合至少四段动作。
- 路径脚本结束后机器狗可靠停止。
