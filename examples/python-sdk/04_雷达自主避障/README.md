# 实验 4：雷达自主避障综合项目

## 本周目标

综合 SDK 通信、状态读取、运动控制和反馈思想，使 Go2 EDU 通过机载 UTLidar
判断箱子障碍并自主绕过。

本实验实现的是**无地图局部避障**：

- 不提前建立地图。
- 不使用 ROS2、Nav2 或 SLAM。
- 根据当前雷达观测决定下一步动作。
- 面向室内平地和明显箱子的课程场景。

## 感知与决策流程

```text
读取 UTLidar 点云
    ↓
过滤无效点、地面和过高点
    ↓
计算左 / 前 / 右区域净空距离
    ↓
前方受阻时选择更宽一侧
    ↓
转向 → 横移 → 通过 → 回正
    ↓
继续前进
```

## 避障状态机

| 状态 | 作用 |
|---|---|
| `forward` | 前方畅通，正常前进 |
| `slow_down` | 障碍接近，降低速度 |
| `assess` | 停止并比较左右净空 |
| `turn` | 朝选择方向转动 |
| `sidestep` | 横移离开原路线 |
| `pass` | 向前通过障碍 |
| `recover` | 横移回归并继续前进 |
| `safety_stop` | 数据超时、无可行方向或状态超时 |

方向一旦选定，本轮绕障期间保持锁定，避免左右反复切换。

## 实验步骤

### 1. 离线观察状态机

```bash
python3 04_雷达自主避障/run_experiment.py --mock --duration 20
```

Mock 场景会在前方生成一个虚拟箱子。观察终端中的左、前、右距离和状态变化。

### 2. 真机只读雷达验证

首次真机运行不要添加 `--arm`：

```bash
python3 04_雷达自主避障/run_experiment.py --interface enp111s0 --duration 30
```

将箱子依次放在前、左、右方向，确认扇区距离变化正确。若无点云数据，按
[真机验证清单](../docs/真机验证清单.md) 探测 DDS 话题和坐标轴。

只读探测命令：

```bash
python3 tools/probe_sdk_topics.py --interface enp111s0
```

### 3. 单箱低速绕障

确认感知正确后再允许运动：

```bash
python3 04_雷达自主避障/run_experiment.py --interface enp111s0 --duration 30 --arm
```

### 4. 多箱障碍赛

逐步增加箱子数量和路线复杂度，每次只调整一组参数，并记录成功率。

## 预期现象

- 箱子进入前方区域后，机器狗先减速再停止判断。
- 机器狗选择空间更大的一侧。
- 绕过箱子后恢复前进。
- 点云超时或两侧均不可通行时停止。
- CSV 记录状态机状态和左、前、右距离。

## 学生任务

1. 绘制一次完整绕障过程中的前方距离曲线。
2. 标注减速、判断、通过和恢复时刻。
3. 分析一次失败绕障的原因并调整一个参数。

## 验收标准

- 单箱连续成功绕行至少 3 次。
- 多箱场景能够完成课程规定路线。
- 左右选择稳定，不反复横跳。
- 雷达数据丢失时可靠停止。
- 能解释本实验与“建图导航”的区别。
